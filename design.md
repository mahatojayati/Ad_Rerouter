# Ad Rerouter - UI and Interaction Design

## 1. Design Philosophy
Ad Rerouter should feel like a productivity tool, not another application competing for attention.
Design language: Minimal / Dark / Quiet / Focused / Typographic

## 2. Overlay
Pitch-black background (`#000000`), dominant centered 5-second countdown timer (`5 -> 4 -> 3 -> 2 -> 1`), followed by motivational quote text beneath.

## 3. Typography
System font stack:
`font-family: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;`

## 4. Animation
Subtle `fade-in` (0.2s) and `fade-out` (0.2s).

## 5. Popup Design
Compact dark mode popup (280px width), active/disabled state indicator dot, subtext, and clear toggle buttons.
